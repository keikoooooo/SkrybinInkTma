# Настройка системы оплаты

## Реализованные функции

### 1. Выбор способа оплаты
- **Банковская карта** - оплата сразу через Telegram Payments
- **Рассрочка** - доступна для заказов от 10 000 ₽ (4 месяца)

### 2. Интеграция с Telegram Payments

Приложение использует встроенный Telegram Payments API для обработки платежей картой.

## Настройка Telegram Payments

### Шаг 1: Настройка бота в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/mybots`
3. Выберите вашего бота
4. Выберите "Payments"
5. Выберите провайдера платежей (например, Stripe, YooMoney, и т.д.)
6. Следуйте инструкциям для настройки

### Шаг 2: Получение токена провайдера

После настройки провайдера вы получите:
- API ключи
- Секретные ключи
- Webhook URL (если требуется)

### Шаг 3: Добавление в переменные окружения

Добавьте в `server-go/.env`:

```env
# Telegram Payments (если требуется)
TELEGRAM_PAYMENT_PROVIDER_TOKEN=your_provider_token_here
```

## Как это работает

### Оформление заказа

1. Пользователь выбирает товар и нажимает "Заказать"
2. На странице оформления выбирает способ оплаты:
   - **Карта** - оплата сразу
   - **Рассрочка** - доступна от 10 000 ₽
3. Заполняет форму (зона, комментарии)
4. Нажимает "Оформить заказ"
5. Заказ создается со статусом `pending`

### Оплата заказа

1. Пользователь переходит на страницу заказа
2. Нажимает "Оплатить"
3. Открывается форма Telegram Payments
4. После успешной оплаты:
   - Статус заказа меняется на `paid`
   - Пользователь перенаправляется в список заказов

### Рассрочка

Для рассрочки:
- Минимальная сумма: 10 000 ₽
- Срок: 4 месяца
- Ежемесячный платеж: сумма / 4

**Примечание:** В текущей реализации рассрочка создает заказ с особым комментарием. Для полноценной интеграции с банком рассрочки нужно подключить соответствующий API.

## Тестовый режим

Если Telegram Payments API недоступен (например, в браузере), используется тестовый режим:
- Платеж обрабатывается автоматически
- Статус заказа меняется на `paid`
- Создается тестовая транзакция

## API для обработки платежей

### Фронтенд

```typescript
import { processTelegramPayment, processInstallmentPayment } from '../utils/payments'

// Оплата картой
const result = await processTelegramPayment({
  orderId: 123,
  amount: 300000, // в копейках
  description: 'Заказ #123',
  userId: 123456789
})

// Рассрочка
const result = await processInstallmentPayment({
  orderId: 123,
  amount: 300000,
  userId: 123456789
})
```

## Тестирование

Для тестирования в браузере:
1. Откройте приложение в обычном браузере
2. Создайте заказ
3. Нажмите "Оплатить"
4. Платеж обработается в тестовом режиме

Для тестирования в Telegram:
1. Откройте приложение в Telegram
2. Убедитесь, что бот настроен для платежей
3. Создайте тестовый заказ
4. Оплатите через Telegram Payments
