# Настройка и запуск фронтенда

## Проблема: Фронтенд не отображается

Если фронтенд не отображается, проверьте следующие шаги:

## 1. Создайте файл .env

Создайте файл `.env` в корне проекта `skryabin-ink`:

```powershell
# В директории skryabin-ink
Copy-Item env.example .env
```

Или создайте вручную файл `.env` со следующим содержимым:

```env
VITE_API_BASE_URL=http://localhost:3000
```

**Важно:** Убедитесь, что порт совпадает с портом вашего Go бэкенда (по умолчанию 3000).

## 2. Установите зависимости (если еще не установлены)

```powershell
cd D:\С\work\skryabin-ink
npm install
```

## 3. Запустите dev сервер

```powershell
npm run dev
```

Сервер запустится на `http://localhost:5173` (или другом порту, который покажет Vite).

## 4. Убедитесь, что бэкенд запущен

В другом терминале запустите Go бэкенд:

```powershell
cd D:\С\work\skryabin-ink\server-go
go run main.go
```

Бэкенд должен быть доступен на `http://localhost:3000`.

## 5. Откройте в браузере

Откройте URL, который покажет Vite (обычно `http://localhost:5173`).

## Проверка работы

1. **Откройте консоль браузера** (F12 → Console)
2. Проверьте, нет ли ошибок подключения к API
3. Если видите ошибки CORS, убедитесь, что в `.env` бэкенда указан правильный `CORS_ORIGIN`

## Типичные проблемы

### Фронтенд не загружается
- Проверьте, что `npm run dev` запущен
- Проверьте, что порт не занят другим приложением

### Ошибки подключения к API
- Убедитесь, что Go бэкенд запущен
- Проверьте `VITE_API_BASE_URL` в `.env`
- Проверьте `CORS_ORIGIN` в `.env` бэкенда

### Белый экран
- Откройте консоль браузера (F12) и проверьте ошибки
- Убедитесь, что все зависимости установлены (`npm install`)

## Для работы в Telegram Mini App

1. Настройте Telegram Bot через BotFather
2. Получите токен бота
3. Добавьте токен в `.env` бэкенда: `BOT_TOKEN=your_token`
4. Настройте Web App URL в настройках бота
5. Откройте приложение через Telegram
