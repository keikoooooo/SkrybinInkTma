# Как настроить и проверить админку

## Способ 1: Через переменную окружения (рекомендуется)

### Шаг 1: Узнайте свой Telegram ID

Есть несколько способов узнать свой Telegram ID:

1. **Через бота @userinfobot** в Telegram:
   - Откройте бота @userinfobot
   - Отправьте любое сообщение
   - Бот вернет ваш ID

2. **Через консоль браузера** (если уже открыто приложение):
   - Откройте DevTools (F12)
   - В консоли выполните:
   ```javascript
   // Если используете Telegram WebApp
   window.Telegram?.WebApp?.initDataUnsafe?.user?.id
   ```

3. **Через профиль в приложении**:
   - Откройте страницу профиля
   - Ваш ID отображается в мета-информации

### Шаг 2: Добавьте ID в переменную окружения

1. Откройте файл `.env` в папке `server-go/` (или создайте его на основе `env.example`)

2. Добавьте или измените строку:
   ```env
   ADMIN_IDS=ваш_telegram_id_здесь
   ```
   
   Если нужно несколько админов, перечислите через запятую:
   ```env
   ADMIN_IDS=123456789,987654321,111222333
   ```

3. Сохраните файл

### Шаг 3: Перезапустите сервер

Остановите сервер (Ctrl+C) и запустите заново:
```bash
cd server-go
go run main.go
```

### Шаг 4: Проверьте админку

1. Откройте приложение в Telegram WebApp
2. Перезагрузите страницу (чтобы создалась новая сессия)
3. Перейдите в профиль - должна появиться кнопка "Перейти в админку"
4. В нижней навигации должна появиться вкладка "Заявки" и "Админ"
5. Откройте `/profile/admin` - должна загрузиться админ-панель с заявками

## Способ 2: Через базу данных (быстрый способ для тестирования)

Если сервер уже запущен и вы знаете свой Telegram ID:

### Вариант A: Через SQL

1. Подключитесь к базе данных:
   ```bash
   psql -U your_user -d skryabin_ink
   ```

2. Выполните SQL запрос (замените `YOUR_TELEGRAM_ID` на ваш ID):
   ```sql
   UPDATE users SET role = 'admin' WHERE id = YOUR_TELEGRAM_ID;
   ```

3. Перезагрузите приложение в браузере

### Вариант B: Через API (если уже есть админ)

Если у вас уже есть доступ к админке, можно изменить роль через API:

```bash
curl -X PUT http://localhost:8080/api/admin/users/YOUR_TELEGRAM_ID/role \
  -H "Content-Type: application/json" \
  -H "X-User-ID: EXISTING_ADMIN_ID" \
  -d '{"role": "admin"}'
```

## Способ 3: Временная проверка через DevTools

Для быстрой проверки без изменения БД, можно временно изменить роль в консоли браузера:

1. Откройте DevTools (F12)
2. В консоли выполните:
   ```javascript
   // Это только для визуальной проверки, не сохраняется в БД
   localStorage.setItem('debug_admin_role', 'admin');
   ```
3. Перезагрузите страницу
4. **Внимание**: Это работает только если в коде есть проверка localStorage (нужно добавить)

## Проверка работы админки

После настройки проверьте:

✅ **В профиле:**
- Видна кнопка "Перейти в админку"
- В мета-информации отображается роль

✅ **В навигации:**
- Появляется вкладка "Заявки" (только для админа)
- Появляется вкладка "Админ" (только для админа)
- Вкладка "Мои заказы" скрыта для админа

✅ **Страница заявок (`/requests`):**
- Загружается список всех заявок
- Видны все статусы заявок
- Отображается общая сумма

✅ **Админ-панель (`/profile/admin`):**
- Загружается список заявок
- Видны все пользователи и их данные
- Можно управлять заявками

## Устранение проблем

### Роль не меняется

1. **Проверьте переменную окружения:**
   ```bash
   # В PowerShell
   $env:ADMIN_IDS
   
   # В Linux/Mac
   echo $ADMIN_IDS
   ```

2. **Убедитесь, что сервер перезапущен** после изменения `.env`

3. **Проверьте логи сервера** - должны быть сообщения о создании сессии

4. **Проверьте в БД напрямую:**
   ```sql
   SELECT id, username, role FROM users WHERE id = YOUR_TELEGRAM_ID;
   ```

### Админка не загружается

1. Проверьте консоль браузера (F12) на ошибки
2. Проверьте Network tab - запросы к `/api/admin/requests` должны возвращать 200
3. Убедитесь, что заголовок `X-User-ID` отправляется с запросами

### Вкладки не появляются

1. Очистите кеш браузера
2. Проверьте, что роль действительно `admin` в ответе API `/api/profile/:id`
3. Проверьте консоль на ошибки React

## Быстрая команда для проверки роли

Выполните в консоли браузера на странице приложения:

```javascript
// Проверить текущую роль пользователя
fetch('/api/profile/YOUR_TELEGRAM_ID', {
  headers: { 'X-User-ID': 'YOUR_TELEGRAM_ID' }
})
  .then(r => r.json())
  .then(data => console.log('Role:', data.role || data.user?.role))
```

Замените `YOUR_TELEGRAM_ID` на ваш реальный Telegram ID.
