# Простая установка Go

## Самый простой способ (рекомендуется)

### Шаг 1: Скачайте Go
1. Откройте браузер
2. Перейдите на: **https://go.dev/dl/**
3. Скачайте файл для Windows (например: `go1.21.5.windows-amd64.msi`)

### Шаг 2: Установите
1. Запустите скачанный `.msi` файл
2. Нажимайте "Next" → "Next" → "Install"
3. Дождитесь завершения установки

### Шаг 3: Перезапустите терминал
**ВАЖНО!** Закройте и откройте PowerShell/терминал заново

### Шаг 4: Проверьте
```powershell
go version
```

Должно показать что-то вроде: `go version go1.21.5 windows/amd64`

### Шаг 5: Установите зависимости проекта
```powershell
cd D:\С\work\skryabin-ink\server-go
go mod download
```

### Шаг 6: Создайте .env файл
```powershell
# Скопируйте пример
Copy-Item env.example .env

# Откройте для редактирования
notepad .env
```

Заполните значения:
- `BOT_TOKEN` - токен вашего Telegram бота
- `DATABASE_URL` - строка подключения к PostgreSQL
- `PORT` - порт (по умолчанию 3000)
- `CORS_ORIGIN` - URL вашего фронтенда

### Шаг 7: Запустите сервер
```powershell
go run main.go
```

---

## Если что-то не работает

### Go не найден после установки?
1. Убедитесь, что вы **перезапустили терминал**
2. Проверьте PATH:
   ```powershell
   $env:PATH -split ';' | Select-String -Pattern 'go'
   ```
3. Если Go не в PATH, добавьте вручную:
   - Откройте "Переменные среды" (Win + R → `sysdm.cpl` → "Дополнительно" → "Переменные среды")
   - В "Переменные пользователя" найдите `Path`
   - Добавьте: `C:\Program Files\Go\bin`
   - Перезапустите терминал

### Нужна помощь?
