# Быстрый старт

## ⚠️ Проблема: Go не установлен

Если вы видите ошибку `go: The term 'go' is not recognized`, значит Go не установлен в системе.

## ✅ РЕШЕНИЕ: Установите Go вручную (2 минуты)

**Самый простой способ:**

1. **Скачайте:** https://go.dev/dl/ (файл `.msi` для Windows)
2. **Установите:** Запустите `.msi` файл → Next → Next → Install
3. **Перезапустите терминал** (важно!)
4. **Проверьте:** `go version`

Подробная инструкция в файле **SETUP.md**

## Решение 1: Автоматическая установка (рекомендуется)

1. **Откройте PowerShell от имени администратора:**
   - Нажмите `Win + X`
   - Выберите "Windows PowerShell (Администратор)" или "Терминал (Администратор)"

2. **Перейдите в директорию проекта:**
   ```powershell
   cd D:\С\work\skryabin-ink\server-go
   ```

3. **Запустите скрипт установки:**
   ```powershell
   .\install-go.ps1
   ```

4. **Перезапустите терминал** (важно!)

5. **Проверьте установку:**
   ```powershell
   go version
   ```

## Решение 2: Ручная установка

1. **Скачайте Go:**
   - Перейдите на https://go.dev/dl/
   - Скачайте файл `go1.21.x.windows-amd64.msi` (или новее)

2. **Установите:**
   - Запустите скачанный `.msi` файл
   - Следуйте инструкциям установщика
   - Go будет установлен в `C:\Program Files\Go`

3. **Перезапустите терминал**

4. **Проверьте:**
   ```powershell
   go version
   ```

## После установки Go

1. **Установите зависимости проекта:**
   ```powershell
   cd D:\С\work\skryabin-ink\server-go
   go mod download
   ```

2. **Создайте файл `.env`:**
   ```powershell
   # Скопируйте env.example в .env и заполните значения
   Copy-Item env.example .env
   # Отредактируйте .env файл
   notepad .env
   ```

3. **Запустите сервер:**
   ```powershell
   go run main.go
   ```

## Если проблемы остаются

- Убедитесь, что вы **перезапустили терминал** после установки
- Проверьте, что Go добавлен в PATH:
  ```powershell
  $env:PATH -split ';' | Select-String -Pattern 'go'
  ```
- Если Go не в PATH, добавьте вручную:
  - `C:\Program Files\Go\bin` (или путь, куда установлен Go)
