    # Настройка Cloudinary для проекта

## Шаг 1: Получение учетных данных

1. Зарегистрируйтесь на [cloudinary.com](https://cloudinary.com)
2. Перейдите в Dashboard
3. Скопируйте:
   - **Cloud Name**
   - **API Key**
   - **API Secret**

## Шаг 2: Настройка переменных окружения

Откройте `server-go/.env` и добавьте:

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

## Шаг 3: Перезапустите сервер

```bash
cd server-go
go run main.go
```

## Как это работает

### Автоматическое определение хранилища

Система автоматически определяет, какое хранилище использовать:

- **Если Cloudinary настроен** (все 3 переменные указаны) → используется Cloudinary
- **Если Cloudinary не настроен** → используется локальное хранилище

### Структура в Cloudinary

Изображения сохраняются в следующей структуре:

```
skryabin-ink/
├── works/          # Фото работ (дизайны тату)
├── artists/       # Аватары мастеров
└── users/         # Фото пользователей
```

### Преимущества Cloudinary

- ✅ Автоматическая оптимизация изображений
- ✅ Автоматическое преобразование форматов (WebP)
- ✅ CDN для быстрой загрузки
- ✅ Автоматический ресайз
- ✅ Безопасное хранение

## Загрузка изображений для проекта

### Способ 1: Через админ-панель (рекомендуется)

1. Откройте админ-панель → "Управление работами"
2. Нажмите "+ Добавить работу"
3. Загрузите фото дизайна
4. Изображение автоматически загрузится в Cloudinary

### Способ 2: Через API

```bash
curl -X POST http://localhost:8080/api/upload/image \
  -H "X-User-ID: YOUR_ADMIN_ID" \
  -F "file=@/path/to/design.jpg" \
  -F "type=work"
```

### Способ 3: Через Cloudinary Dashboard

1. Зайдите в Cloudinary Dashboard
2. Перейдите в Media Library
3. Создайте папку `skryabin-ink/works`
4. Загрузите изображения
5. Скопируйте URL и используйте при создании работы

## Примеры изображений для проекта

### Рекомендуемые изображения:

1. **Фото работ (works):**
   - Примеры тату из портфолио
   - Разные стили (реализм, минимализм, олдскул и т.д.)
   - Размер: минимум 800x800px
   - Формат: JPG или PNG

2. **Аватары мастеров (artists):**
   - Фото мастера
   - Размер: 400x400px (квадрат)
   - Формат: JPG

3. **Фоновые изображения:**
   - Для главной страницы
   - Размер: 1200x600px
   - Формат: JPG

## Оптимизация изображений

Cloudinary автоматически:
- Конвертирует в WebP для современных браузеров
- Оптимизирует качество (q_auto:best)
- Сжимает без потери визуального качества

### Ручная оптимизация перед загрузкой

Рекомендуется оптимизировать изображения перед загрузкой:

1. **Используйте инструменты:**
   - [TinyPNG](https://tinypng.com) - сжатие PNG/JPG
   - [Squoosh](https://squoosh.app) - онлайн оптимизатор
   - Photoshop "Save for Web"

2. **Рекомендации:**
   - Фото работ: до 2MB
   - Аватары: до 500KB
   - Фоновые: до 1MB

## Проверка работы

После настройки:

1. Загрузите тестовое изображение через админ-панель
2. Проверьте URL в ответе - должен быть Cloudinary URL
3. Откройте URL в браузере - изображение должно загружаться
4. Проверьте в Cloudinary Dashboard - файл должен появиться

## Миграция существующих изображений

Если у вас уже есть локальные изображения:

1. Загрузите их через админ-панель (они автоматически попадут в Cloudinary)
2. Или используйте Cloudinary Upload API для массовой загрузки

## Безопасность

- ✅ API Secret хранится только на сервере
- ✅ Публичные URL безопасны
- ✅ Можно настроить подписи URL для дополнительной защиты

## Мониторинг использования

В Cloudinary Dashboard вы можете:
- Видеть количество загруженных файлов
- Отслеживать трафик
- Управлять квотой (бесплатный тариф: 25GB)

## Устранение проблем

### Ошибка "Cloudinary credentials not configured"
- Проверьте, что все 3 переменные указаны в `.env`
- Убедитесь, что сервер перезапущен после изменения `.env`

### Изображения не загружаются
- Проверьте интернет-соединение
- Проверьте правильность учетных данных
- Посмотрите логи сервера

### URL не работает
- Убедитесь, что используется `SecureURL` (HTTPS)
- Проверьте настройки безопасности в Cloudinary
