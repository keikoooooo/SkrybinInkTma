## Запуск

### 1. Запустите бэкенд (Go)

```powershell
cd D:\С\work\skryabin-ink\server-go
go run main.go
```

Бэкенд запустится на `http://localhost:3000`

### 2. Запустите фронтенд (Vite)

```powershell
cd D:\С\work\skryabin-ink
npm run dev
```

Фронтенд запустится на `http://localhost:5173`

### 3. Откройте в браузере

Откройте `http://localhost:5173` - фронтенд автоматически будет делать запросы к бэкенду через прокси.

## Как это работает

1. Фронтенд делает запрос к `/api/catalog`
2. Vite прокси перехватывает запрос и отправляет на `http://localhost:3000/api/catalog`
3. Бэкенд обрабатывает запрос и возвращает данные
4. Данные возвращаются во фронтенд

## Использование API утилиты

Вместо прямых `fetch` запросов используйте утилиту:

```typescript
import { API } from '../utils/api'

// Получить каталог
const data = await API.catalog.get()

// Создать заказ
await API.orders.create(orderData, userId)

// Получить профиль
const profile = await API.profile.get(userId)
```

## Проверка работы

1. Откройте консоль браузера (F12)
2. Перейдите на страницу каталога
3. Должны увидеть запрос к `/api/catalog` в Network tab
4. Данные должны загрузиться и отобразиться

## Troubleshooting

### Ошибка подключения к API
- Убедитесь, что бэкенд запущен на порту 3000
- Проверьте консоль браузера на ошибки

### CORS ошибки
- В dev режиме прокси решает проблему CORS автоматически
- В production убедитесь, что `CORS_ORIGIN` в `.env` бэкенда указан правильно

### Данные не загружаются
- Проверьте, что база данных настроена и миграции выполнены
- Проверьте логи бэкенда на ошибки
