# Как загружать фотографии дизайнов

## Быстрый способ (через админ-панель)

### Шаг 1: Откройте админ-панель

1. Войдите как администратор
2. Перейдите в профиль → "Перейти в админку"
3. Нажмите кнопку **"Управление работами"**

### Шаг 2: Добавьте работу

1. Нажмите **"+ Добавить работу"**
2. Нажмите **"Загрузить фото дизайна"**
3. Выберите изображение с компьютера или телефона
4. Дождитесь загрузки (появится превью)
5. При необходимости добавьте описание
6. Нажмите **"Добавить"**

Готово! Фото дизайна теперь отображается в портфолио на главной странице.

---

## Альтернативный способ (через API)

### Через curl

```bash
# 1. Загрузите изображение
curl -X POST http://localhost:8080/api/upload/image \
  -H "X-User-ID: YOUR_ADMIN_ID" \
  -F "file=@/path/to/design.jpg" \
  -F "type=work"

# Ответ:
# {
#   "ok": true,
#   "url": "http://localhost:8080/uploads/images/works/abc123.jpg"
# }

# 2. Создайте работу с полученным URL
curl -X POST http://localhost:8080/api/admin/works \
  -H "X-User-ID: YOUR_ADMIN_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "image_url": "http://localhost:8080/uploads/images/works/abc123.jpg",
    "caption": "Описание дизайна"
  }'
```

---

## Требования к изображениям

- **Форматы:** JPG, JPEG, PNG, GIF, WEBP
- **Максимальный размер:** 10MB
- **Рекомендуемый размер:** до 5MB для быстрой загрузки
- **Разрешение:** любое (рекомендуется минимум 800x800px)

---

## Где хранятся фотографии

### Локальное хранение (разработка)

Фотографии сохраняются в:
```
server-go/uploads/images/works/
```

Доступны по URL:
```
http://localhost:8080/uploads/images/works/filename.jpg
```

### Облачное хранение (продакшен)

Для продакшена рекомендуется использовать Cloudinary. См. `IMAGE_STORAGE_GUIDE.md` для настройки.

---

## Управление работами

### Просмотр всех работ

- Откройте админ-панель → "Управление работами"
- Все загруженные работы отображаются в виде сетки

### Удаление работы

1. Откройте "Управление работами"
2. Найдите нужную работу
3. Нажмите **"Удалить"**
4. Подтвердите удаление

**Внимание:** При удалении работы изображение также удаляется с сервера.

## Советы

1. **Используйте качественные фото:**
   - Хорошее освещение
   - Четкий фокус
   - Минимум фона

2. **Оптимизируйте размер:**
   - Используйте сжатие перед загрузкой
   - Формат WebP дает лучшее сжатие

3. **Добавляйте описания:**
   - Стиль тату
   - Размер работы
   - Особенности

4. **Организуйте работы:**
   - Загружайте регулярно
   - Обновляйте портфолио
   - Удаляйте старые/неактуальные работы

---

## Решение проблем

### Фото не загружается

1. Проверьте размер файла (макс. 10MB)
2. Убедитесь, что формат поддерживается
3. Проверьте права доступа к папке `uploads/`
4. Посмотрите логи сервера

### Фото не отображается

1. Проверьте URL изображения
2. Убедитесь, что сервер запущен
3. Проверьте настройки `PUBLIC_URL` в `.env`
4. Проверьте CORS настройки

### Ошибка доступа

1. Убедитесь, что вы вошли как администратор
2. Проверьте заголовок `X-User-ID` в запросах
3. Проверьте переменную `ADMIN_IDS` в `.env`

---

## Для продакшена

При деплое на продакшен:

1. **Настройте Cloudinary** (см. `IMAGE_STORAGE_GUIDE.md`)
2. **Или используйте S3/CDN** для хранения
3. **Настройте автоматическое резервное копирование**
4. **Ограничьте доступ** к папке uploads
